# HCI


Prototype and Building
During sprint 3, we will turn our selected design into an interactive web prototype. The prototype will  be built outside WordPress using HTML,  CSS, and JavaScript, as discussed with our client.(we’ll use figma to display this).
The prototype will include functional navigation and interactive elements rather than only static screenshots. At minimum, users should  be able to navigate between the major pages, access  the three primary calls  to action, and  interact with the classroom reading request, book purchasing, and sponsorship flows/donation to  the extent possible within the staging environment. We will use GitHub as our shared repository.
